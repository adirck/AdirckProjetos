# Rocha DNS & Task Defender - クイックガイド

開発者：Alexandre Rocha。すべてのファイルを展開し、管理者として Setup.exe を実行します。言語を選択し、保護ポリシーを確認します。旧 Soma バージョンがある場合は先にアンインストールしてください。

インストールの最後に通知のタイトル、メッセージ、連絡先、QR 画像を設定します。入力中にプレビューが更新され、ボタンで実際の通知ウィンドウを確認できます。保存する前にキャンセルするとインストールを中止します。

添付可能な形式：PDF（最初のページのみ）、PNG、JPEG/JPG、BMP、GIF、TIFF。ローカルで PNG に変換します。連絡先から QR を生成する機能ではなく、添付画像の QR 内容も検証しません。

通知領域の A.R アイコン：緑は確認完了・問題なし、黄は確認中または一時停止、赤は注意が必要です。右クリックで開く、監視開始、一時停止、編集、寄付、終了を選べます。閉じる・最小化は非表示にするだけで、終了すると監視が止まります。

15 秒ごとに確認し、IPv4 DNS を 8.8.8.8 / 8.8.4.4 に修復して通知します。HOSTS は hosts_old_DDMMYYYY に保存して初期化し、etc に hosts_old_* がある間は 60 秒ごとに通知します。正当な HOSTS エントリも削除され、内部名の解決に影響する場合があります。IPv6、プロキシ、ブラウザーのセキュア DNS は変更しません。

インストール後すぐに起動し、以後はインストールした管理者アカウントのログイン時に起動します。Windows サービスではなく、ログイン前や別ユーザーでは自動起動しません。

インストール先は %ProgramFiles%\RochaDefender です。MessageEditor.exe で通知を編集し、Uninstall.exe で選択した言語の確認を行って削除します。スタートメニューと Windows のインストール済みアプリからも削除できます。設定、QR、ログ、バックアップ、hosts_old_*、現在のネットワーク設定は保持されます。ログは %LOCALAPPDATA%\RochaDefender にあります。
